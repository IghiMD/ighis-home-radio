## 🔄 Akcie ktoré MUSÍŠ spraviť ručne (sandbox to nevedel)

### 1. Rotuj credentials, ktoré boli v kóde / chate

- **AzuraCast API key** (zverejnený v handoff doc): `a85d9da3d0f92d98:c66239a262d91c7f5de7b4341a1f24d2` → regeneruj v AC admin
- **MariaDB heslo** `yCmt7rpz9Gqp` → ALTER USER v containeri
- **Admin heslo** `Ighi@Kika_2025!` (bolo hardcoded vo viacerých PHP súboroch + git history) → nové heslo, najlepšie hashnuté:
  ```bash
  php -r "echo password_hash('NoveSilneHeslo!', PASSWORD_DEFAULT).PHP_EOL;"
  # vlož výstup do config.php ako ADMIN_PASSWORD = '$2y$...'
  ```
  Nový `login.php` automaticky detekuje či je `ADMIN_PASSWORD` hash (`$2y$` / `$argon2`) a použije `password_verify()`.

### 2. Vyčisti git history

Kompromitované hesla sú stále v starých commitoch. Buď:
- **(jednoduchšie)** Ber to ako riziko a iba zmeň heslo/key — ak je repo súkromné a nikto nepáčil, OK
- **(čisté)** `git filter-repo --replace-text` alebo `BFG` na prepísanie histórie

### 3. PWA ikony

`manifest.json` teraz neodkazuje na neexistujúce PNG-čka. Ale pre ozajstný "Install app" prompt v Chrome / Edge potrebuješ **192×192** a **512×512 PNG**:
- realfavicongenerator.net (upload favicon.svg, vygeneruj balík)
- alebo `inkscape -w 192 -h 192 favicon.svg -o icon-192.png` (lokálne na Macu má brew Inkscape)

Po vygenerovaní pridaj späť do `manifest.json`:
```json
{ "src": "/icon-192.png", "sizes": "192x192", "type": "image/png", "purpose": "any maskable" },
{ "src": "/icon-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any maskable" }
```

### 4. Self-host og:image

Aktuálne `og:image` ukazuje na `https://i.imgur.com/Ym67jVJ.jpeg`. Imgur môže URL deaktivovať a Facebook si cacheuje OG image. Pre rich previews ideál:
- **1200×630 PNG/JPG** (FB / LinkedIn / Slack)
- **1200×600** (X/Twitter)
- self-hosted: `final_public_html/og-image.jpg`
- update v `index.html` `og:image` a `twitter:image`

- Pridaj `https://www.ighishomeradio.com/` ako property
